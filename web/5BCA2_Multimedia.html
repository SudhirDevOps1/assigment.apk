Page 1 of 4Question 1 · Definition of multimedia

Definition of Multimedia

The word multimedia is made of two parts — multi, meaning many, and media, meaning the ways in which information is presented. Together they mean the use of more than one medium at the same time in a single presentation. In computing, multimedia is the integration of text, graphics, images, sound, video and animation inside one digital system.

That last word, interaction, is what separates true multimedia from a film or a book. A typical multimedia application lets the user click, choose, type or drag, and the content responds in front of them.

Linear and Non-linear Multimedia

In linear multimedia the story runs in one fixed order from start to finish, like a slide show, so the viewer can only watch. In non-linear multimedia the user is given control and jumps to any branch he likes; almost all modern teaching and business software is non-linear.

Page 2 of 4Question 1 · Components of multimedia

Components of Multimedia

Every multimedia system is built from six components, each doing one job.

How the Components Work Together

None of these components is useful alone. Text gives the facts and instructions, graphics and images give the picture, sound and video give the movement and the voice, and animation joins them into one controlled flow. A single piece of educational software may show a written lesson, an animated diagram of the heart, a recorded explanation and a short test at the end — and the user moves between them at will. Hardware makes this possible, because a computer can store and play sound and moving pictures as easily as it stores text.

Page 3 of 4Question 1 · Applications

Applications of Multimedia

(a) Education: lectures become video, diagrams become animations and every topic can be replayed as often as the student likes.

(b) Entertainment: films carry picture and sound together, and games join all six components at once.

(c) Business and advertising: a product is shown, rotated, zoomed and compared before it is bought.

(d) Medicine: body parts are shown as 3-D models so a surgeon can practise before operating.

(e) Journalism: a live newsroom mixes recorded video, sound and text into one report.

(f) Engineering: a design is walked through as a virtual walkthrough before it is built.

(g) Government: citizens learn and apply for services through a single screen.

(h) Virtual reality and gaming: the user walks inside a computer-built world and every movement is answered instantly.

From these eight uses one conclusion follows. Multimedia earns its place only where the subject itself is better understood when it can be seen and heard. Where a list of names or a table of figures would do just as well, adding sound and motion only wastes time and confuses the message. That is why the same subject may need no multimedia at all in one lesson and a great deal of it in the next.

HTML Example

Text, image, audio and video together in one page — the whole idea of multimedia in a single file.

The same file without a video tag still works on a computer that cannot play it, because the controls attribute gives the user a play and pause button and the width keeps the picture inside the page. The source tag names the file and its type, so the browser knows how to play it.

multimedia.html
<!DOCTYPE html>
<html>
<head><title>My Multimedia Page</title></head>
<body>
  <h1>Welcome</h1>
  <p>This page uses several media together.</p>
  <img src="college.jpg" alt="College photo" width="320">
  <audio controls>
    <source src="song.mp3" type="audio/mpeg">
  </audio>
  <video controls width="320">
    <source src="clip.mp4" type="video/mp4">
  </video>
</body>
</html>

Conclusion

Multimedia is not one medium but several working together, under the user's control.

Page 1 of 4Question 2 · Introduction + JPEG, PNG

Introduction to Image File Formats

An image file format is the standard way a picture is written on disk. The format decides how colours are stored, whether the file is compressed, whether transparency is possible and which programs can open it. Choosing wrongly costs a great deal: the same picture may be 40 KB in one format and 4 MB in another.

1. JPEG (Joint Photographic Experts Group)

JPEG is a lossy format built for photographs. It splits the picture into 8×8 blocks, converts each block into frequencies and deletes the weak ones, so the file is small but the fine detail is softened. It does not support transparency.

2. PNG (Portable Network Graphics)

PNG is lossless: nothing is thrown away, so the picture stays exact. It supports a transparent background, which is why it is the normal choice for logos, icons and screenshots, at the cost of a larger file than JPEG for photographs.

Page 2 of 4Question 2 · The other formats

3. GIF is the oldest web format. It holds only 256 colours but supports simple animation and transparency.

4. BMP is an uncompressed Windows bitmap — perfect quality, very large files, used only inside Windows.

5. TIFF is lossless, very high quality and supports many pages, so printers and scanners use it.

6. WebP is Google's modern format. It is both lossy and lossless and is roughly 25–35 % smaller than JPEG or PNG at the same quality.

7. SVG is a vector format: it stores lines and shapes, so a logo can be enlarged to any size with no loss.

8. RAW is exactly what the camera sensor recorded, with almost no processing, so a photographer can adjust the picture fully later. The files are the largest of all and used only in professional work.

Page 3 of 4Question 2 · Differences

Differences Between the Image Formats

Formats are compared on two separate axes. The first asks how the picture is built: a raster image is a grid of coloured dots and goes blocky when enlarged, while a vector image is made of lines and shapes and stays sharp at any size. The second asks how the file is squeezed: lossy compression throws detail away to save space, while lossless compression only squeezes the pattern and keeps every pixel.

Page 4 of 4Question 2 · Python program
Python Program

One picture saved in three formats — using the Pillow (PIL) library.

Image.open reads the picture once and keeps it in memory, so the same image can be written out several times without being loaded again. The quality argument is the only setting that matters for JPEG: a lower number gives a much smaller file and a visibly softer picture. PNG and BMP take no such argument, because neither throws anything away. The last loop simply prints the name of every file that has now been written to the folder.

formats.py
# store one picture in three different formats
from PIL import Image

img = Image.open("photo.jpg")
print("original :", img.size, img.mode)

img.save("copy.jpg", "JPEG", quality=75)   # lossy, small
img.save("copy.png", "PNG")                # lossless, exact
img.save("copy.bmp", "BMP")                # uncompressed, huge

for name in ("copy.jpg", "copy.png", "copy.bmp"):
    print(name, "saved")

Output

original : (640, 480) RGB
copy.jpg saved
copy.png saved
copy.bmp saved

Conclusion

The right format is decided by the job, never by fashion.

Page 1 of 4Question 3 · Definition of animation

Definition of Animation

Animation is the technique of creating an illusion of movement by showing a series of still pictures one after another very quickly. Each picture is slightly different from the one before it, and when they arrive fast enough the human eye joins them into one smooth motion. Animation is therefore not one moving picture — it is many still pictures played at speed.

The reason this works is a property of human vision called the persistence of vision. When the eye sees a still image, the image stays in the brain for about one-tenth of a second after it has disappeared. If the next image arrives before that time runs out, the brain does not notice the gap and reads the whole set as continuous movement.

This also explains why an animation must be shown at a steady speed. If the frames arrive too slowly, each one is seen separately and the illusion breaks. If the frames arrive at an uneven rate, the motion looks jerky even though the pictures are correct.

How Animation is Created

An animator first plans the storyboard — a rough sketch of every important moment — then draws the keyframes that hold those moments and lets the computer fill in the in-betweens between them. The finished frames are then stored in order and played at a chosen frame rate, measured in frames per second (fps).

Page 2 of 4Question 3 · Types of animation

Types of Animation

Traditional 2-D animation is drawn frame by frame by hand on transparent celluloid, so an animator may produce thousands of drawings for a few minutes of film.

Computer 2-D animation is drawn once on a screen and then moved by the computer, so only the moving parts have to be redrawn and the same material can be reused many times.

3-D CGI builds a complete model in three dimensions and renders a fresh frame from it for every moment, which is why the camera can move freely around the object.

Stop-motion photography photographs real objects that have been moved a very small amount each time, and the movement appears when the pictures are joined.

Motion graphics animation works on text, logos and shapes, and procedural animation is produced entirely by code, with no artist drawing anything at all.

Page 3 of 4Question 3 · Key terms + uses

Key Terms Related to Animation

Frame: one single still picture of the series.
Frame rate: how many frames are shown each second; film uses 24 fps.
Key frame: a frame that the artist draws by hand and that fixes the position of the object at one moment.
Storyboard: the rough sketch of the whole sequence, made before any drawing begins.
Sprite: one small image that is moved around a background.

Uses and Applications of Animation

Animation is used in films and cartoons, in video games, in advertisements and in educational software, and it is the base of virtual reality, where the user moves inside a computer-built world and the picture answers every movement at once.

Animation earns its keep in teaching because it shows a change that a still picture cannot show. A plant growing, a current flowing, a cylinder turning into a cone and a light ray bending — each of these is understood in seconds when it moves, and may take a whole paragraph when it is only described. This is why animation is used to explain physics, mathematics, chemistry and the working of machines.

Page 4 of 4Question 3 · CSS animation
CSS Animation Example

A moving square made with @keyframes and the animation property.

move.html
<!DOCTYPE html>
<html>
<head>
<style>
  @keyframes slide {
    from { left: 0px;   background: red; }
    to   { left: 260px; background: blue; }
  }
  .box {
    width: 80px; height: 80px; position: relative;
    animation: slide 3s linear infinite;
  }
</style>
</head>
<body>
  <div class="box"></div>
</body>
</html>

How the Example Works

@keyframes slide names the movement and describes its starting state with from and its ending state with to. The .box rule then plays it: animation: slide 3s linear infinite means run the movement once every three seconds, at an even speed, and never stop. Because the box is placed with position: relative, the left value in the keyframes moves it away from the left edge of the page.
